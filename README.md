# Escuela
Proyecto académico desarrollado en Python para la gestión de una institución educativa, aplicando programación modular, Programación Orientada a Objetos, entidades relacionadas, operaciones CRUD y control de versiones con Git y GitHub.
## Integrantes

- Castañeda Caicedo David — Desarrollo de entidades de personas
- Piedrahita Velázquez Xilena — Desarrollo de estructura académica
- Bueno Cuadrado Fabian Leonardo — Desarrollo de evaluación y calificaciones
  
El sistema permite gestionar información relacionada con estudiantes, profesores, cursos, grupos, matrículas, periodos académicos, evaluaciones y notas.
El proyecto permite realizar operaciones CRUD sobre las entidades y demostrar las relaciones existentes entre ellas.
